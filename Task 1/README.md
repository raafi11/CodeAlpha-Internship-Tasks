# TASK 1 — Data Redundancy Removal System

## Overview
A Python-based cloud database management system that detects and prevents duplicate data entries before storing them in the database.

The system validates incoming data against existing records and only stores unique entries, improving database efficiency and reducing redundancy.

---

## Features
- Duplicate data detection
- Validation mechanism for new entries
- Prevention of redundant records
- SQLite database integration
- Unique user data storage
- Simple and lightweight implementation

---

## Technologies Used
- Python
- SQLite
- VS Code

---

## How It Works
1. User data is entered into the system
2. The program checks existing records
3. Duplicate email or phone entries are detected
4. Duplicate data is rejected
5. Unique data is stored in the database
